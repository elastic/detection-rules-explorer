AWS Bedrock Unusual Tool Selection

Last updated 7 days ago on 2026-11-06
Created 21 days ago on 2026-10-23

About

A machine learning job has detected that an Amazon Bedrock model requested a tool that is rare for a caller, compared with that caller's own history. A model that suddenly selects an unfamiliar tool can indicate that an AI agent was redirected toward an unexpected capability, for example through prompt injection or unsafe delegation (OWASP ASI02, Tool Misuse and Exploitation). The tool name is a requested operation in the model output, not a confirmed tool execution.

False Positive Examples
A newly deployed or newly enabled tool is rare by definition until it has been used regularly. Confirm any recent change to the agent's tool set. Seasonal or rarely used legitimate tools, such as monthly reporting or maintenance tools, can appear unusual when they are used.
