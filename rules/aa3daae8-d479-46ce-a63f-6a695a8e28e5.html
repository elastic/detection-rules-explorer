GenAI Prompt Contains Cryptographic Hash String

Last updated 3 days ago on 2026-11-06
Created 3 months ago on 2026-08-18

About

Detects hex-encoded hash strings (MD5, SHA-1, SHA-256, SHA-512) within GenAI prompt or completion text. The security_ai ML model has identified one or more candidate strings whose character distribution matches a cryptographic digest. Attackers may pass hashes in prompts to exfiltrate credentials for offline cracking, to reference stolen data without sending plaintext, or as part of prompt injection payloads that encode malicious instructions as hex data.

False Positive Examples
Security or forensics workflows that send file hashes to a model for threat intelligence lookup or malware triage. Review the surrounding context and verify the hash does not correspond to a credential or sensitive artifact. Development tooling that includes git commit SHAs, Docker image digests, or package checksums in prompts for CI/CD automation.
