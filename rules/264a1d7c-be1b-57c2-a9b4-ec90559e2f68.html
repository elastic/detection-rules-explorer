AWS EKS Container Created with Excessive Linux Capabilities

Last updated 10 days ago on 2026-10-21
Created 3 months ago on 2026-08-03

About

This rule detects a container deployed with one or more dangerously permissive Linux capabilities. An attacker with the ability to deploy a container with added capabilities could use this for further execution, lateral movement, or privilege escalation within a cluster. The capabilities detected in this rule have been used in container escapes to the host machine.

False Positive Examples
Some container images require the addition of privileged capabilities. This rule leaves space for the exception of trusted container images. To add an exception, add the trusted container image name to the query field, aws.eks.audit.requestObject.spec.containers.image.
