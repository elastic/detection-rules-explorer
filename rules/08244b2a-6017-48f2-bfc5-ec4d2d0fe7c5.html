GCP Vertex AI Safety Filters Set to BLOCK_NONE

Last updated 8 days ago on 2026-10-02

About

Detects Vertex AI GenerateContent requests that set safety_settings.threshold to BLOCK_NONE. That threshold disables category blocking for the listed harm categories when clients explicitly send safetySettings. Attackers and careless apps use BLOCK_NONE to weaken built-in Gemini filters.
