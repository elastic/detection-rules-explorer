Azure Event Hub Namespace Deleted

Last updated 9 days ago on 2026-11-12
Created 9 days ago on 2026-11-12

About

Identifies the deletion of an Azure Event Hub namespace ("Microsoft.EventHub/namespaces/delete"). Event Hub namespaces are a common egress path for Azure diagnostic, activity, and sign-in logs to SIEMs, deleting a namespace can sever that telemetry pipeline, impairing defenses and monitoring. This rule excludes known cloud-provider egress networks to reduce infrastructure-automation noise.
