Kubernetes Pod Creation Using Common Debug or Base Images

Last updated 3 days ago on 2026-11-18
Created 7 months ago on 2026-05-04

About

Detects successful Kubernetes pod creation requests using commonly abused base and debugging container images such as BusyBox, Alpine, Ubuntu, Netshoot, and network multitool variants, as well as container runtime and image-build images such as Docker-in-Docker (dind), Podman, BuildKit, Buildah, and Kaniko. Base and debug images are frequently used by attackers to deploy short-lived or interactive "throwaway" containers for reconnaissance, payload staging, or command execution. Container runtime and build images are used to run nested containers or build images on-host, bypassing registry-based image controls. This is a New Terms rule that surfaces the first time a given source, user agent, and user deploy such an image within the lookback window.
