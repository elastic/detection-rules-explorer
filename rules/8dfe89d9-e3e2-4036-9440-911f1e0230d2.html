ELF Binary Created in System Directory by Suspicious Process

Last updated 22 days ago on 2026-10-07
Created 22 days ago on 2026-10-07

About

Identifies an executable from a suspicious or writable location creating an ELF binary in a system binary, configuration, or library directory. This may indicate an adversary attempting to install or masquerade a malicious executable in a trusted system location.

text code block:
✄𐘗file where host.os.type == "linux" and event.action in ("rename", "creation") and file.Ext.header_bytes like "7f454c46*" and
process.executable like (
  "/tmp/*", "/var/tmp/*", "/dev/shm/*", "/run/*", "/var/run/*", "/boot/*", "/sys/*", "*/www/html/*",
  "/lost+found/*", "/proc/*", "/var/mail/*", "/var/www/*", "/mnt/*", "/media/*", "*/wp-content/*",
  "*/wp-includes/*", "*/wp-admin/*", "?memfd:*", "memfd:*"
) and
file.path like (
  "/bin/*", "/usr/bin/*", "/usr/local/bin/*", "/sbin/*", "/usr/sbin/*", "/usr/local/sbin/*", "/etc/*",
  "/lib/*", "/lib32/*", "/lib64/*", "/libx32/*", "/usr/lib/*", "/usr/lib32/*", "/usr/lib64/*",
  "/usr/libx32/*", "/usr/local/lib/*", "/usr/local/lib32/*", "/usr/local/lib64/*", "/usr/local/libx32/*",
  "/libexec/*", "/usr/libexec/*", "/usr/local/libexec/*", "/var/lib/*"
)
