Suspicious Linux Process Connection to Bulletproof Hosting ASN

Last updated 21 days ago on 2026-09-17
Created 21 days ago on 2026-09-17

About

This rule detects outbound connection attempts from unusual Linux process locations or common living-off-the-land utilities to autonomous systems associated with bulletproof or high-abuse hosting. Adversaries often stage payloads in world-writable or web directories and beacon to infrastructure that ignores abuse reports, including providers such as Storm Industries, Ecatel/IP Volume, Aeza, and Proton66.

Query

text code block:
✄𐘗network where host.os.type == "linux" and event.type == "start" and event.action == "connection_attempted" and
(
  process.executable like (
    "/tmp/*", "/var/tmp/*", "/dev/shm/*", "/run/*", "/var/run/*", "/boot/*", "/sys/*", "*/www/html/*",
    "/lost+found/*", "/var/mail/*", "/var/www/*", "/mnt/*", "/media/*", "/proc/*/fd/*", "?memfd:*", "memfd:*",
    "*/wp-content/*", "*/wp-includes/*", "*/wp-admin/*"
  ) or
  process.name in (
    "curl", "wget", "ftp", "tftp", "scp", "rsync", "bash", "dash", "sh", "tcsh", "csh", "zsh", "ksh", "fish",
    "busybox", "timeout", "env", "bun"
  ) or
  process.name like (".*", "python*", "perl*", "php*", "ruby*", "lua*", "node*", "deno*")
) and
