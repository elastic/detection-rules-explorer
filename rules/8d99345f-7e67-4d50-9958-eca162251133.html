NetScaler Superuser Binding Followed by Authentication Control Removal

Last updated a month ago on 2026-10-27
Created a month ago on 2026-10-27

About

Identifies a successful NetScaler command that binds a system user to the built-in superuser command policy, followed within 15 minutes on the same appliance, from the same user and source address, by a successful command that disables endpoint analysis or unbinds an authentication or VPN session policy. Attackers with command execution on NetScaler ADC or Gateway, including after CVE-2026-88771, have used this sequence to retain a local administrator and remove login controls that would block that account.

Query
✄𐘗
text code block:
✄𐘗sequence by observer.hostname, user.name, source.ip with maxspan=15m
  [any where data_stream.dataset == "citrix_adc.log" and
    citrix.name == "CMD_EXECUTED" and
    citrix_adc.log.status in~ ("Success", "Done") and
    (
      process.command_line regex~ """(bind|.*[^a-z0-9_]bind) system user [^ ]+ superuser([ "].*)?""" or
      citrix.detail regex~ """(bind|.*[^a-z0-9_]bind) system user [^ ]+ superuser([ "].*)?""" or
      citrix_adc.log.message regex~ """(bind|.*[^a-z0-9_]bind) system user [^ ]+ superuser([ "].*)?"""
    )]
  [any where data_stream.dataset == "citrix_adc.log" and
    citrix.name == "CMD_EXECUTED" and
    citrix_adc.log.status in~ ("Success", "Done") and
    (
      process.command_line regex~ """(set|.*[^a-z0-9_]set) authentication epaaction .* -defaultepagroup no_auth([ "].*)?""" or
      citrix.detail regex~ """(set|.*[^a-z0-9_]set) authentication epaaction .* -defaultepagroup no_auth([ "].*)?""" or
      citrix_adc.log.message regex~ """(set|.*[^a-z0-9_]set) authentication epaaction .* -defaultepagroup no_auth([ "].*)?""" or
      process.command_line like~ (
        "unbind authentication vserver * -policy *",
        "unbind authentication policylabel * -policyname *",
        "unbind vpn vserver * -policy *"
      ) or
      citrix.detail like~ (
        "*unbind authentication vserver * -policy *",
        "*unbind authentication policylabel * -policyname *",
        "*unbind vpn vserver * -policy *"
      ) or
      citrix_adc.log.message like~ (
        "*unbind authentication vserver * -policy *",
        "*unbind authentication policylabel * -policyname *",
        "*unbind vpn vserver * -policy *"
      )
    )]
