AWS Bedrock Unusually Large Tool-Request Batch

Last updated 5 days ago on 2026-11-06
Created 19 days ago on 2026-10-23

About

A machine learning job has detected an unusually large number of tool requests generated in a single Amazon Bedrock model response for a caller, compared with that caller's own history. Large batches can indicate over-invocation of tools by an AI agent, for example after prompt injection, ambiguous instructions, or unsafe delegation (OWASP ASI02, Tool Misuse and Exploitation). The count is requested operations in the model output, not confirmed tool executions.

False Positive Examples
A legitimate change in agent behavior, such as a new workflow, a bulk-processing task, or a prompt update that asks the model to call many tools in one turn, can produce a larger batch than the caller's history. Confirm with the agent owner. A newly onboarded caller has little history, so early batches can look unusual until the model has learned its normal range.
