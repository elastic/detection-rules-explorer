Entra ID Unusual Cloud Device Registration

Last updated 6 days ago on 2026-11-16
Created a year ago on 2025-06-13

About

Detects a sequence of Microsoft Entra ID audit events indicative of cloud device registration using the default device profile of ROADtools (roadtx). The sequence begins with an "Add device" operation from the Device Registration Service where the user agent is "Microsoft.OData.Client/*", the recorded cloud device OS build is a ROADtools default ("10.0.19041.928" or "10.0.19045.2006") and the display name follows the default "DESKTOP-" pattern, followed within the same correlation ID by "Add registered users to device" or "Add registered owner to device", which completes the registration and binds the device to a user. This flow is used to establish persistence or acquire a Primary Refresh Token (PRT). The OS build and naming are tool defaults, so this is a high-fidelity but evadable indicator.

Query

text code block:
✄𐘗sequence by azure.correlation_id with maxspan=30s
[any where data_stream.dataset == "azure.auditlogs" and
    azure.auditlogs.identity == "Device Registration Service" and
    event.action == "Add device" and
    azure.auditlogs.properties.additional_details.value like "Microsoft.OData.Client/*" and
    (
        `azure.auditlogs.properties.target_resources.0.modified_properties.3.new_value` like "*10.0.19041.928*" or
        `azure.auditlogs.properties.target_resources.0.modified_properties.3.new_value` like "*10.0.19045.2006*"
    ) and
    `azure.auditlogs.properties.target_resources.0.modified_properties.4.new_value` like "*DESKTOP-*"]
[any where data_stream.dataset == "azure.auditlogs" and
    event.action in ("Add registered users to device", "Add registered owner to device")]
