ELF Payload Staged in a Suspicious Directory

Last updated 21 days ago on 2026-10-07
Created 21 days ago on 2026-10-07

About

Identifies an ELF file created in a temporary, shared-memory, runtime, mail, or web directory by a transfer utility, file-manipulation utility, interpreter, or executable running from a suspicious location. This may indicate an adversary transferring or staging a Linux payload for subsequent execution.

Query
✄𐘗
text code block:
✄𐘗file where host.os.type == "linux" and event.action in ("rename", "creation") and
file.Ext.header_bytes like "7f454c46*" and (
  process.name in (
    "curl", "wget", "ftp", "tftp", "scp", "rsync", "busybox", "timeout", "env", "cp", "mv",
    "install", "dd", "tee", "touch", "tar", "gzip", "gunzip", "bzip2", "bunzip2", "xz",
    "unxz", "zip", "unzip", "7z", "bun"
  ) or
  process.name like (".*", "python*", "perl*", "php*", "ruby*", "lua*", "node*", "deno*") or
  process.executable like (
    "/tmp/*", "/var/tmp/*", "/dev/shm/*", "/run/*", "/var/run/*", "/boot/*", "/sys/*", "*/www/html/*",
    "/lost+found/*", "/proc/*", "/var/mail/*", "/var/www/*", "/mnt/*", "/media/*", "*/wp-content/*",
    "*/wp-includes/*", "*/wp-admin/*", "?memfd:*", "memfd:*"
  )
) and
file.path like (
  "/tmp/*", "/var/tmp/*", "/dev/shm/*", "/run/*", "/var/run/*", "/var/mail/*",
  "*/www/html/*", "*/wp-content/*", "*/wp-includes/*", "*/wp-admin/*"
)
