Entra ID App Permission Grant by Rare User

Last updated 14 days ago on 2026-11-12
Created 14 days ago on 2026-11-12

About

Identifies the first time, within a lookback window, a user grants application permissions in Entra ID ("Add app role assignment to service principal" or "Add delegated permission grant"). Adversaries abuse application role assignments and delegated permission grants to obtain durable, token-based access to tenant data without requiring interactive consent. This is a New Terms rule keyed on the granting user; known cloud-provider egress networks are excluded.

False Positive Examples
Administrators grant application and delegated permissions as part of legitimate onboarding and integration work. The New Terms logic baselines known administrators; a newly seen user granting permissions, especially from an unusual network, warrants review.
