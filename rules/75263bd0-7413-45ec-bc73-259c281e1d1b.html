Elastic Security Detection Rules

About

Hunts for a Cisco Secure Firewall Management Center (FMC) system log showing the web-service user invoking the privileged package validation utility against `/var/tmp/license.tmp`. Cisco identifies this activity as a possible indicator of FMC exploitation. The indicator is associated with CVE-2026-20079 and is also documented for CVE-2026-20316, so a match establishes likely FMC exploitation but does not identify which vulnerability provided initial access.

✄𐘗FROM logs-* METADATA _id, _index
| WHERE @timestamp > NOW() - 30 days
| WHERE message LIKE "*www*"
    AND message LIKE "*USER=root*"
    AND message LIKE "*/usr/local/sf/bin/package_info.pl*"
    AND message LIKE "*/var/tmp/license.tmp*"
    AND message LIKE "*--lsm*"
    AND (
        message LIKE "*sudo:*"
        OR log.syslog.appname == "sudo"
        OR process.name == "sudo"
    )
| KEEP
    @timestamp,
    host.name,
    observer.name,
    log.syslog.appname,
    process.name,
    user.name,
    message,
    _index,
    _id
| SORT @timestamp DESC
| LIMIT 1000
